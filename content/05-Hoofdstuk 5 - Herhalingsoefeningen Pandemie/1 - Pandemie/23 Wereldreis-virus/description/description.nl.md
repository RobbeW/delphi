## Gegeven

Een virus kan van stad naar stad reizen.

In elke stad komen er evenveel lokale besmettingen bij.

## Gevraagd

* Vraag het aantal steden.
* Vraag het aantal besmette reizigers in de eerste stad.
* Vraag hoeveel lokale besmettingen er per stad bijkomen.
* Print per stad het totaal aantal besmettingen.

#### Rekenregel

Per stad:

```
reizigers = reizigers + lokale_besmettingen
```

#### Voorbeeld

Voor deze invoer:
```
3
5
2
```

moet je programma exact dit printen:
```
Stad 1: 7 besmettingen
Stad 2: 9 besmettingen
Stad 3: 11 besmettingen
```
