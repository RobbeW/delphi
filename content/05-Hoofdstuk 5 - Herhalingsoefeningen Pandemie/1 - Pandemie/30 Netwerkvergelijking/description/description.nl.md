## Gegeven

Je vergelijkt twee contactnetwerken.

Voor elke persoon krijg je het aantal contacten in netwerk A en in netwerk B.

## Gevraagd

* Vraag hoeveel personen je onderzoekt.
* Vraag per persoon het aantal contacten in netwerk A.
* Vraag per persoon het aantal contacten in netwerk B.
* Tel de contacten per netwerk op.
* Print beide totalen.
* Print welk netwerk meer contacten heeft.

#### Rekenregel

Tel alle contacten van netwerk A op in `totaal_a`.

Tel alle contacten van netwerk B op in `totaal_b`.

#### Voorbeeld

Voor deze invoer:
```
3
3
2
4
3
3
3
```

moet je programma exact dit printen:
```
Netwerk A: 10 contacten
Netwerk B: 8 contacten
Netwerk A heeft meer contacten.
```
