## Gegeven

Leeftijd kan mee bepalen hoeveel risico iemand loopt.

In deze oefening bepaal je de risicogroep voor meerdere personen met een `for`-lus.

## Gevraagd

* Vraag het aantal personen.
* Vraag per persoon de leeftijd.
* Bepaal per persoon de risicogroep.
* Tel hoeveel personen in elke risicogroep zitten.
* Print de drie aantallen.

#### Rekenregel

* vanaf 65 jaar: `hoog`
* vanaf 45 jaar: `matig`
* jonger dan 45 jaar: `laag`

#### Voorbeeld

Voor deze invoer:
```
4
70
45
18
64
```

moet je programma exact dit printen:
```
Laag risico: 1
Matig risico: 2
Hoog risico: 1
```
