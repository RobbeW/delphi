Project Delphi

Project Delphi is a browser learning environment where students write, run and practise Python with automatic feedback.

Students practise data types, variables, conditions, loops and input. The assignments connect Python to computational thinking, mathematical exercises and challenging puzzles.

What is included in Delphi?

The setup is familiar: students see their code on the left, the assignment on the right and direct feedback at the bottom. The menu guides them step by step through the course.

Python runtime in the browser

Based on Papyros, with regular output and interactive input()questions.

Catalogue with chapters

The exercises come from content/catalog.json, built from a Dodona-like folder structure.

Test cases and feedback

YAML and JSON test files drive the test cases, with a summary and details for each test case.

Store progress locally

Code, attempts, working time and evaluation status are stored locally without an account or cloud.

Learning platform and board book

Use the learning platform for the exercises. The board book is intended for whole-class use on the smartboard and shows the same syllabus alongside the Python editor.

Start learning platform Start board book

Board book prototype for the classroom

The board book is the smartboard version: you see the same syllabus page as the students have on paper, can write on it and open the Python editor alongside it. Pages, annotations and code are stored per class on this device when you press Save.

This is a functional prototype. Automatic background saving is not available yet. Touch, stylus and smartboard use are still being tested; for now, only run trusted lesson code.

Getting started

In class, you work with the board book and the learning environment. The board book contains the PDF, lets you make annotations together with your students and run example code. The learning environment contains hundreds of exercises for practising and assessing the subject matter.

  1. 1 Start with the board book. Project the syllabus, choose a class and navigate together to the right page.
  2. 2 Annotate and run example code. Write on the PDF, highlight important concepts and open code examples in the editor to run them together.
  3. 3 Let students practise. Then open the learning platform and let students work independently on exercises that match the material discussed.
  4. 4 Assess and adjust. Use the automatic feedback and PDF export to discuss and assess results and determine the next lesson step.
